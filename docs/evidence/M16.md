## What changed

react-dockable-desktop 7.3.0's Phase 2 branding, ported ([0018](../decisions/0018-brand-surfaces-and-corners.md)).
rdd's change was redone as one prefix-aware transform (radius scale, a role table for the surface
tokens, the guarded base, and the handful of element rules that painted surfaces). It was checked
first on rdd itself: run on rdd 7.2.0 it produces rdd 7.3.0's stylesheet line for line, apart
from the light-mode on-accent rule vdd already had. Replaying rdd's diff directly failed 25 of 67
hunks, which is why it wasn't used.

- `src/index.css`: 55 corners scaled; 240 surface declarations derived (rdd has one more:
  `--rdd-placeholder-bg`, a token vdd doesn't have — the preview letter's own rule reads the same
  derived value instead); 50 derived values on `:root`, placed after the main `:root` block so
  M14's token check keeps reading only the documented tokens; the edge drop preview on the accent.
- Playground: `?bs=`, `?bt=`, `?rs=`. M15's scene helpers moved to
  `scripts/gates/lib/branding-scenes.mjs` (M15 re-run green after the move).
- Docs: theming chapter, README, CHANGELOG 1.4.0, ADR 0018, PARITY.md, plan. Version 1.4.0.
