## What changed

react-dockable-desktop 7.12.0 and 7.12.1's pop-out windows, ported in their final form
([0022](../decisions/0022-popout-windows.md)), in seven stages. The full record, with every
divergence, is [docs/plans/popout-port-report.md](../plans/popout-port-report.md).

- **P1** document-aware internals (`domContext`, `documentRegistry`), Escape and click-to-activate per document.
- **P2** the store (`setPoppedOut`, return places, `saveLayout`), the windows registry, the frame
  (a Teleport into the child's body with the preserved slot), the menu items.
- **P3** the head copy, `adoptedStyleSheets`, the `<html>`/`<body>` mirror.
- **P4** `popoutWrapper`, `usePanelWindow()`, `isPoppedOut`, toasts per window.
- **P5** managed widgets in their own window.
- **P6** focus across windows, the taskbar entry.
- **P7** manual chapter 15 and the chapter updates, PARITY, ADR 0022, the demo, the release files,
  these rules and the M13 tour.

## The demo, by hand in real Chrome

`npm run demo` (:5190), driven by playwright-core with `channel: 'chrome'`:

- **Leaflet map:** its tab menu reads Float Window, Open in new window, Minimize Panel, Close Tab.
  The item opens `/popout.html` with the panel inside (the same node, 16 tiles loaded, the title
  "Leaflet Map"); the taskbar shows "Leaflet Map: in its own window". The zoom button zooms; a
  mouse drag does **not** pan (the map pane's transform is unchanged), as expected: Leaflet 1.9
  follows a drag on the main `document`. "Return to desktop" puts it back docked, the same node.
- **Cameras widget:** its title menu ends with "Open in new window"; the window holds the same table
  (`data-vdd-popout-kind="widget"`, "Shown: floating"), its frame icon opens the widget's menu there
  ("Back into the map"), a row click works, and "Back into the panel" puts it back in the map
  ("Shown: panel"), the same node.
- No page errors. A first run showed a 404 in the pop-out (its page had no favicon); the demo's
  `popout.html` now carries the demo's icon.
