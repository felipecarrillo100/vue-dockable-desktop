## What exists now

| | |
|---|---|
| Build | Vite library mode → `dist/index.js` (ESM), `dist/index.cjs`, `dist/index.d.ts` via `vue-tsc`, `dist/styles.css` |
| Types | `vue-tsc --noEmit`, `strict` + `noUncheckedIndexedAccess` + `verbatimModuleSyntax` |
| Tests | Vitest + `@vue/test-utils` + jsdom; browser-level checks kept out of jsdom by design |
| Lint | ESLint 10 flat config, `typescript-eslint` + `eslint-plugin-vue` |
| Gate | `npm run gate -- M<n>` — the runner in [scripts/gate.mjs](../../scripts/gate.mjs) |

`vue` is a peer dependency (`^3.4.0`) and is external in the bundle: bundling it would give a
consumer two Vue instances, which breaks reactivity and `provide`/`inject` across them.

## The gates are non-vacuous — proven, not asserted

`npm run gate:selftest` breaks each rule on purpose and asserts the gate catches it:

```
  caught  css-prefix catches a bare class selector
  caught  css-prefix catches an unprefixed custom property
  caught  api-surface catches an undocumented export
  caught  api-surface catches a removed export
  caught  counts catches a dropped test
  caught  M1 catches a missing build artefact
  selftest: ok — all 6 gate rules are non-vacuous
```

This matters more than M1's own result. Integrity rule 5 exists because a check that cannot
fail proves nothing, and the whole autonomous scheme rests on the gates being real. The
self-test restores every file it touches, and is run whenever a gate is added or changed
rather than on every milestone, since it mutates sources while running.

## Design notes worth keeping

- **`counts` ratchets.** Floors rise automatically as tests are added, so the recorded floor
  is always "what we had last time it was green". Dropping below it fails; raising it is
  normal progress.
- **`api-surface` seeds itself** on first run, then refuses silent change. Growing the public
  surface is a one-line statement of intent in `api-surface.json`.
- **`css-prefix` checks both directions** — the stylesheet's own selectors *and* the classes
  components emit. rdd shipped three rules whose class no component rendered; jsdom could
  never catch it because it does not load the stylesheet.
- **A milestone with no gate script cannot pass.** The runner treats a missing
  `scripts/gates/m<n>.mjs` as a failure rather than a skip.
